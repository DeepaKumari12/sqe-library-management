# SQE Library Management

This project is a Library Management System developed as part of the Software Quality Engineering Lab. The system will manage books and library members and will provide basic book borrowing and returning functionality.

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/DeepaKumari12/sqe-library-management.git
   cd sqe-library-management
```
2. Ensure Python 3.10+ is installed:
```bash
   python --version
```
3. (Optional) Create and activate a virtual environment:
```bash
   python -m venv venv
   venv\Scripts\activate
```
